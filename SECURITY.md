# 🛡️ Autopoiesis Security Policy & Threat Model

## 🔒 Overview & Zero-Trust Architecture

Autopoiesis accepts foreign computational genomes generated by community breeders across the globe. Because executing arbitrary foreign code is inherently untrusted, Autopoiesis implements a **Zero-Trust, Multi-Tiered Immune Defense** architecture:

```
[ Incoming Genome Package ]
            │
            ▼
[ 1. Phase 0: Static Zero-Trust Security Audit (`autopoiesis.core.security`) ]
  - Python AST whitelist (bans `os`, `sys`, `subprocess`, `socket`, `eval`, `open`, etc.)
  - Native C/Rust token whitelist (bans `<unistd.h>`, `<windows.h>`, `system()`, `fork()`, sockets)
            │ (Passes Static Audit)
            ▼
[ 2. Phase 1: Isolated Subprocess Sandbox (`autopoiesis.core.sandbox`) ]
  - Quarantined process boundary (intercepts `SIGSEGV`, `0xC0000005`, memory corruption)
  - Strict execution timeout quarantine (mitigates CPU DoS & infinite loops)
            │ (Executes Cleanly)
            ▼
[ 3. Phase 2: Deterministic Apoptotic Gate (`autopoiesis.core.apoptosis`) ]
  - 100% Numerical equivalence verification against ground-truth baseline (tolerance 1e-6)
  - Monotonic hardware timer speedup verification (rejects performance regressions)
            │ (Passes Verification)
            ▼
[ 4. Phase 3: Atomic In-Memory Splice (`autopoiesis.core.hotswap`) ]
  - Living thread-safe memory hot-swap with full history rollback
```

## 🚫 Explicitly Prohibited Capabilities

Any submitted chromosome containing or attempting the following will be **immediately rejected** by the security gate:
1. **System & File Operations**: Reading or writing files outside temporary compile targets, invoking shell commands (`system`, `exec`, `subprocess`), or modifying environment variables.
2. **Network Operations**: Opening raw sockets, HTTP requests, DNS queries, or outbound connections.
3. **Sandbox Escape & Introspection**: Accessing Python internals (`__subclasses__`, `__globals__`, `__code__`, `globals()`, `locals()`).
4. **Obfuscation**: Dynamic eval (`eval()`, `exec()`, `compile()`, base64 bytecode payloads).
